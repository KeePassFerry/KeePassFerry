# Security policy

English · [Deutsch](#deutsch)

## Reporting a vulnerability

Please do not report security problems in public issues.

Use GitHub's private reporting instead: open the [Security tab](https://github.com/KeePassFerry/KeePassFerry/security) and choose **Report a vulnerability**. Only you and the maintainers can see the report. If you have no GitHub account, write to KeePassFerry@gmail.com. E-mail is not encrypted, so please describe the problem only briefly at first.

Helpful details are the affected version, the browser, the steps to reproduce and what an attacker could achieve.

KeePassFerry is maintained in spare time, so there is no guaranteed response time. We will answer as soon as we can and tell you when a fix is released.

## Supported versions

Only the latest release of the extension and the plugin receives security fixes.

## Scope

In scope are the browser extension, the KeePass plugin, the native messaging host and the connection between them.

An attacker who already runs code under your Windows account can also read keystrokes and browser data. KeePassFerry cannot fully protect against that, but reports that make such an attack easier are welcome.

# Sicherheitsrichtlinie

## Sicherheitslücke melden

Bitte melde Sicherheitsprobleme nicht in öffentlichen Issues.

Nutze stattdessen die private Meldefunktion von GitHub: Öffne den [Reiter Security](https://github.com/KeePassFerry/KeePassFerry/security) und wähle **Report a vulnerability**. Die Meldung sehen nur du und die Maintainer. Ohne GitHub-Konto schreib an KeePassFerry@gmail.com. E-Mails sind nicht verschlüsselt, beschreibe das Problem daher zunächst nur knapp.

Hilfreich sind die betroffene Version, der Browser, die Schritte zum Nachstellen und was ein Angreifer damit erreichen könnte.

KeePassFerry wird in der Freizeit gepflegt, eine feste Antwortzeit gibt es deshalb nicht. Wir antworten so bald wie möglich und sagen dir, wenn eine Korrektur veröffentlicht ist.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils neueste Version von Erweiterung und Plugin.

## Geltungsbereich

Dazu gehören die Browser-Erweiterung, das KeePass-Plugin, der Native-Messaging-Host und die Verbindung zwischen ihnen.

Wer bereits Code unter deinem Windows-Konto ausführt, kann auch Tastatureingaben und Browserdaten lesen. Davor kann KeePassFerry nicht vollständig schützen, Meldungen, die einen solchen Angriff erleichtern, sind aber willkommen.
